# 码道 CodeArts 用户规模增长（二）：增长能力池

> 本篇是"弹药库"，不是路线图。目标是**穷举可能性**，排序和取舍见 [（三）优先级与落地路线](./03-roadmap-and-metrics.md)。
>
> 每条能力标注三类标签：
> - `[对齐]` 友商已验证，不做会持续失血
> - `[差异]` 基于华为独有资产，友商抄不走
> - `[脑洞]` 业界尚无人做透，风险与回报都高

共 **56 条**，分 8 个大类。

---

## A. 准入层：把门槛砍到地板（8 条）

**A1. 免登录试用（Guest Mode）** `[对齐]`
网页版 / 插件首次启动，不要求登录即可完成 3~5 次完整 Agent 任务。产生价值之后再引导注册。
> 机理：账号环节是漏斗中最大单段流失。Claude Code 的 Guest Pass 证明"先给完整体验、后谈账号"是有效的。
> 关键：免登录会话的产出（代码、会话记录）要能在注册后**无损继承**，否则用户会觉得白干。

**A2. 轻量登录通道** `[对齐]`
除华为云账号外，支持华为账号（终端侧，鸿蒙用户已有）、手机号一键登录、微信 / Gitee / GitHub OAuth。实名/企业认证延后到需要企业能力时再要求。

**A3. 免费额度兜底不中断（Auto-Free）** `[对齐]`
高级模型额度耗尽后，自动降级到低成本模型继续服务（变慢/变弱，但**绝不弹"额度已用完"**）。参考文心快码的 Auto-Free 设计。
> 这是本清单里我认为**优先级最高的单条**。

**A4. 额度从"月池"改为"日流"** `[对齐]`
每日首次登录发放当日额度，连续签到递增。参考千问办公（免费 500 / 标准 1000 / 高级 2000 每日登录积分）。
> 一箭双雕：既解决额度焦虑，又造出一个天然的 DAU 回访钩子。

**A5. 行为换额度（任务中心）** `[对齐]`
完成新手引导、首次跑通 CI、提交一个 Skill、写一篇实践案例、邀请一位好友、通过一次认证考试 —— 都发额度。
> 把运营目标直接翻译成用户可见的任务清单，是最便宜的增长基础设施。

**A6. 身份免费计划** `[差异]`
学生 / 教师 / 开源 maintainer / 华为认证持证者 / 鸿蒙开发者联盟成员，凭身份领取高额度（对标 Copilot Student：无限补全 + 200 credits/月）。
> 华为有 ICT 学院覆盖数千所高校、有认证体系、有鸿蒙开发者联盟 —— 认证接口是现成的，几乎零成本。

**A7. 竞品置换计划** `[脑洞]`
持有 Cursor / Copilot / Claude Code / Qoder 有效订阅凭证的用户，换取码道专业版 3~6 个月。
> 精准命中"已被教育过、且愿意付费"的高价值人群，获客成本远低于泛投放。附带价值：拿到竞品用户的迁移反馈。

**A8. 一键迁移助手** `[脑洞]`
从 Cursor / Trae / VS Code / Copilot 一键导入：快捷键、主题、扩展、`.cursorrules` / `AGENTS.md` 规则文件、MCP 配置、自定义 Skill、甚至历史会话。
> **切换成本是 AI IDE 竞争的真正护城河，而目前所有人都在被动等待用户手动迁移。** 做一个"5 分钟无痛搬家"的向导，是可以单独当作投放素材的能力。

## B. 激活层：让第一次使用必然成功（7 条）

**B1. 仓库体检报告（打开即有价值）** `[对齐]`
用户第一次用码道打开一个已有工程，**不需要输入任何 prompt**，自动生成：项目 Wiki、模块依赖图、技术栈清单、代码风险与坏味道 Top 10、新人上手路径。
> 参考 Qoder 的 Repo Wiki / 知识引擎（公开数据称上线后采纳率提升 11 个百分点）。
> 这是"零 prompt 展示价值"的最佳范式 —— 新用户不知道该问什么，那就别让他问。

**B2. 首次任务必成功模板库** `[对齐]`
内置 20 个开箱即用模板：鸿蒙小应用、SpringBoot CRUD、数据看板、爬虫、Excel 批处理、CLI 工具……点一下就跑出可运行结果。
> 新用户的第一次失败几乎等于永久流失。

**B3. 零配置云端开发环境** `[差异]`
把码道直接内置进**华为开发者空间**（已提供 180 小时免费云主机、预置鲲鹏/昇腾/鸿蒙开发能力）。用户不装任何东西，浏览器打开就能跑 Agent。
> 华为已经建好了这块基础设施，却和码道没打通，这是明摆着的内部协同红利。

**B4. 想法起步模式（非专业开发者入口）** `[脑洞]`
不从代码起步，从"我想做一个……"起步，自动生成可运行的应用 + 可预览链接。参考 Lovable 的 browser-first 流程。
> 这是通往泛用户的必经之路，也是 B 类模板的自然延伸。

**B5. 新手 Agent 伴学模式** `[对齐]`
第一周内，Agent 在执行任务时用可折叠的方式解释"我为什么这么做"，并推荐下一步可尝试的能力。

**B6. 中文场景优化的展示** `[对齐]`
国产工具的中文语料优势是已被数据验证的差异点，但需要在产品里**可感知**（中文注释生成、中文需求理解、中文技术文档检索）。

**B7. 失败可恢复（Checkpoint / 回滚）** `[对齐]`
Agent 改坏了代码可一键回滚到任意检查点。这不是增长功能，但它决定用户敢不敢把 Agent 放开用 —— 不敢放开用就不会有高频。

## C. 留存层：给回访制造理由（7 条）

**C1. 每日签到 + 连续加成** `[对齐]`（同 A4，从留存视角）

**C2. 云端异步任务 + 跨端推送** `[对齐]`
长任务提交到云端执行，完成后推送到手机 / 企业微信 / 微信。用户下班了任务还在跑，第二天早上回来看结果。
> 参考 Qoder Cloud Agents、WorkBuddy 的企微/微信连接器远程下发任务。
> **这是把"工具"变成"员工"的关键一步，也是唯一能让用户在不打开 IDE 时仍然想起你的机制。**

**C3. 个人代码力周报 / 月报 / 年报** `[对齐]`
生成"你本周让 Agent 写了 X 行代码、节省 Y 小时、最常用的 Skill 是 Z、在团队排第 N"，**自带可晒图**。
> 参考 Trae 年度产品报告的传播效果。这条同时是 D 类（传播）能力。

**C4. 长期记忆与个人知识资产** `[对齐]`
用户的偏好、代码风格、项目背景、常用 Skill 沉淀成个人资产，用得越久越懂你。
> 这是**迁移成本**的来源。友商（Qoder 的 Repo 知识库、记忆能力）已经在做。

**C5. 每周 Skill 推荐** `[对齐]`
根据用户技术栈，每周推送 3 个可能有用的 Skill / MCP，一键安装。
> 低成本的回访触达，同时激活 L4 生态。

**C6. 额度有效期机制** `[对齐]`
奖励积分设 31 天有效期（Trae 同款）。有效期把"存量"变成"使用压力"。

**C7. 团队/项目空间的协同沉淀** `[对齐]`
规则、Skill、知识空间在团队内共享。一旦团队的工程规范沉淀在码道里，个人就无法单独离开。

## D. 传播层：让产出物自己去拉新（11 条）

> **这是当前码道的最大空白，也是我认为脑洞空间最大的一层。核心思路只有一句：把用户在码道里产生的一切，都变成一个可以被别人看到、且别人可以接手继续玩的东西。**

**D1. 邀请裂变（基础版）** `[对齐]`
双向发额度、阶梯奖励、封顶、31 天有效期、严格的新用户认定。规则直接参考 Trae：双方各 500 积分、单人封顶 3500、必须是从未注册过的新账号且完成登录。

**D2. 邀请裂变（进阶版）：Guest Pass + 延迟奖励** `[脑洞]`
邀请链接本身给对方**7 天专业版完整体验**（降低对方决策门槛，而不是给一堆看不懂的积分）；邀请人的大额奖励在**对方留存 7 天且完成 N 次有效会话后**才发放。
> 参考 Claude Code 的 Guest Pass（3 个名额 + 转化付费后给推荐人 $10~15 额度）。
> 好处：奖励与真实价值对齐，防刷天然成立，且奖励发的是额度不是现金 —— 推荐人为了消耗额度会继续留在生态里。

**D3. 作品广场 + 一键发布 + Remix** `[脑洞/高价值]`
Agent 生成的应用可一键发布为公网可访问链接，带作者信息；任何访客可以 **Fork / Remix**（复刻后继续修改），而 Remix 必须注册账号。
> 这是 Lovable 增长引擎的核心（6000 万+ 项目、9 亿+ 月访问）。**国内 AI 编程工具几乎没有一家做透，是明确的空地。**
> 对码道的额外意义：作品广场可以和**鸿蒙元服务 / 华为应用市场**打通 —— 用户在码道做的东西能一键上架，这是别人给不了的落地闭环。

**D4. 会话链路分享页** `[脑洞]`
把一次 Agent 解题的完整轨迹（需求 → 计划 → 工具调用 → diff → 测试结果）导出成一个漂亮的、可交互的公开分享页，可嵌入博客。
> 技术博主每天都在手工做这件事。把它产品化 = 给几万内容创作者发免费生产工具，每一份产出都带你的水印和"用码道打开"的入口。

**D5. 一键生成竖屏演示视频** `[脑洞]`
把一次 Agent 会话自动剪成 30~60 秒竖屏短视频：自动加速、高亮 diff、配字幕、带片尾二维码。
> AI Coding 在抖音/B站/小红书是流量洼地，但制作门槛把大多数开发者挡在外面。**降低内容生产成本 = 放大传播供给。** 这条是本清单里传播杠杆最大的一条。

**D6. Skill / Rule 深链分享** `[对齐]`
`codearts://install?skill=xxx` 形式的一键安装链接，可以贴在群里、文章里、README 里。
> 参考 Claude Code 的 marketplace add 机制。让每个 Skill 作者都成为分发节点。

**D7. 代码评审 / 修复结论卡片** `[脑洞]`
Agent 完成 Code Review 或 Bug 修复后，生成一张美观的结论卡片（问题、修复、影响面、测试），适合直接甩到工作群 / PR 评论。
> 群里每个人都会看到这张卡片，这是零成本的组织内渗透。

**D8. 排行榜与战绩体系** `[对齐]`
个人周榜 / 团队榜 / 高校榜 / 开源项目榜。参考社区实践：**排行榜必须给及时反馈** —— 用户花时间邀请别人，如果始终不知道是否成功，动力很快耗尽。

**D9. 可展示的能力徽章** `[差异]`
在 Gitee / GitHub / 掘金 / 牛客 / 简历上可展示的"码道认证徽章"，与华为认证体系打通。
> 徽章 = 用户自愿帮你打广告，且理由是"对我有好处"。

**D10. 开源仓库 Badge** `[对齐]`
给开源项目提供 `Powered by 码道` / `Built with CodeArts` 徽章 + 免费额度权益。
> 每个 README 都是一个长期展示位。Lovable、Replit、Vercel 都吃过这个红利。

**D11. IM 群机器人** `[对齐]`
企业微信 / 微信群 / 钉钉群里 `@码道` 直接派任务，结果回到群里。
> 参考 WorkBuddy 打通企微/微信下发任务。**群是中国企业的真实工作界面**，进了群等于对群里每个人曝光。

## E. 供给侧：让第三方替你拉新（8 条）

**E1. 去中心化的 Skill / 插件市场** `[对齐/关键]`
不做纯审核制中心化商店，改为：**任何 Git 仓库（Gitee / GitHub / 企业内 GitLab）只要包含市场清单文件，就是一个市场**，用户可自行添加。官方市场只负责精选和安全筛查。
> 直接参考 Claude Code 的架构（官方市场 172 插件 + 社区市场 + 任意 Git 仓库自建）。
> **核心价值：供给增长不再受官方运营人力限制。** WorkBuddy 能有 8 万+ 技能，靠的就是开放。

**E2. 创作者分成机制** `[脑洞/高价值]`
Skill / Agent 被他人调用所产生的 token 消耗，按比例返还给作者（返还为额度，或提现）。
> **目前全行业的技能市场都是"用爱发电"。谁先把技能创作变成一门可持续的生意，谁就能虹吸整个赛道的优质供给。**
> 附带效应：专业创作者会主动为自己的 Skill 引流，等于免费的分销网络。

**E3. Agent 雇佣市场（双边平台）** `[脑洞]`
用户把调教好的专家 Agent（"鸿蒙适配专家""SpringBoot 重构专家""信创迁移专家"）挂出来接单，别人付积分调用。
> 从"工具市场"升级到"劳动力市场"。WorkBuddy 的"100+ 领域专家模板"已经在往这个方向走，但还是官方供给。

**E4. 官方框架共建计划** `[差异]`
为 openEuler / openGauss / MindSpore / 昇思 / 仓颉 / ArkTS / Spring / Vue 等框架提供官方 Skill 包，并在框架文档站挂"用码道一键上手"入口。
> 华为自己就是 openEuler / OpenHarmony / 仓颉 的主导者（开源鸿蒙社区已有 3 万+ Star、80 多万 PR），这是**内部协同就能拿下的分发位**。

**E5. ISV / 伙伴白标** `[差异]`
让合作伙伴把码道能力嵌进自己的产品（参考 WorkBuddy 开放平台首批百家伙伴、9 款联名硬件、20+ 行业应用）。
> 华为云有成体系的伙伴网络，这条的渠道基础是现成的。

**E6. MCP / ACP 双向互通** `[对齐]`
既能装别人的 MCP Server，也**能被别的 Agent 当工具调用**。
> 被调用意味着即使用户主用竞品，码道仍然在链路里（DevEco CLI 就是这个思路 —— 它"支持市面主流编程 Agent"）。

**E7. 开源一个轻量 CLI 内核** `[脑洞]`
把码道 CLI 的内核开源（模型与云端能力仍走商业化）。
> OpenClaw 用四个月做到 GitHub 38 万+ Star、超越 Linux 登顶，npm 主包月下载超千万 —— **开源本身就是 2026 年最高效的分发渠道**。
> 附带案例：腾讯云推出 OpenClaw 一键部署镜像后，首周轻量应用服务器新增申购中近 45% 选择了该镜像。开源项目可以直接变成云产品的获客入口。

**E8. 企业私有技能市场** `[差异]`
企业可在内网自建 Skill 市场，沉淀本企业的工程规范和领域知识。
> 这是企业侧最强的粘性来源：企业的知识资产一旦沉淀进来，迁移成本极高。

## F. 华为独有牌：别人抄不走的（9 条）

**F1. 鸿蒙 AI 编程第一入口** `[差异/战略级]`
1100 万鸿蒙注册开发者、HarmonyOS 6 终端超 8000 万台、应用与服务 40 万款 —— 这是中国最大的、且**尚未被 AI 编程工具充分服务**的开发者池。
具体动作：ArkTS 增训模型 + 接入 DevEco CLI + 复用华为已开放的 **2000 多万字**鸿蒙官方知识资源 + HMAF 2.0 / Ark Agentic Framework 的 Skill 开发支持。

**F2. 一键 Android → 鸿蒙迁移 Agent** `[差异/爆款候选]`
输入 Android 工程（甚至 APK），输出可编译运行的鸿蒙工程 + 迁移报告 + 待人工确认清单。
> **为什么这条可能是单点爆款**：鸿蒙有 40 万应用，而安卓生态有数百万应用，迁移是巨大的、明确的、痛的需求；迁移任务天然一次性消耗大量 token（利好商业化）；迁移成功的案例极具传播性；而且这件事**只有华为体系能做好**。
> 建议配套：迁移成功的应用可一键提交鸿蒙应用市场，形成"开发 → 上架 → 分发"闭环。

**F3. 信创迁移与调优 Agent（x86→鲲鹏 / CUDA→CANN / Oracle→GaussDB）** `[差异]`
> 这是政企、金融、能源、运营商的**刚性需求 + 强合规约束**场景，友商基本无法进入。且这类客户的采购单价高、席位规模大，是 B2B2C 的最佳入口。

**F4. 华为工程规范 Skill 包** `[差异]`
把华为自身研发体系的规范（代码规范、安全编码、测试要求、评审检查项）产品化成可直接安装的 Rules / Skills 包，对外开放。
> "华为多年研发实践、千亿级代码库沉淀"这句话目前只是宣传语。**把它变成用户能装进自己项目的具体东西，才是可感知的差异化。**

**F5. 华为认证：AI 编程工程师方向** `[差异/被低估]`
在 HCIA/HCIP 体系下设立"AI 辅助软件开发工程师"认证，实操环节必须使用码道完成。
> 华为认证每年数十万考生、在国内招聘市场有实际含金量。这条同时命中：强制激活、零成本获客、高校渠道（ICT 学院覆盖数千所高校）、简历外溢。
> 类比：AWS/阿里云的认证体系为其云产品输送了大量长期用户。**这是华为独有、且已建好的用户放大器，目前完全没和码道联动。**

**F6. 高校课程 / 实验 / 毕设包** `[差异]`
与 ICT 学院合作，提供 AI 编程课程包、实验环境（跑在华为开发者空间免费云主机上）、毕设模板。教师是渠道，学生是未来五年的开发者主力。

**F7. 终端侧入口** `[差异]`
- 鸿蒙电脑应用市场上架（WorkBuddy 已作为首个桌面办公智能体上架，华为自家产品没理由缺席）；
- MateBook 预置 / 购机赠专业版年卡；
- 昇腾开发板、开发者套件捆绑权益。

**F8. HDC / 花粉俱乐部 / 开发者社区联动** `[差异]`
HDC 现场发放高额度体验、开发者案例中心的案例共创权益（2026 生态政策已新增此项）与码道绑定、"开发者空间用户创作广场"作为码道作品广场的冷启动内容源。

**F9. 华为内部 dogfooding 数据当背书** `[差异]`
华为自身十万量级研发人员的真实使用数据（采纳率、效率提升、缺陷下降）是最强的 B 端说服材料。
> 参考 WorkBuddy 的路径：内测阶段就有 2000+ 非技术岗员工每天使用，这既是产品打磨，也是公测时的第一批种子和口碑源。

## G. 破圈：走出开发者（8 条）

> 这一层决定**最终天花板**。如果目标是"用户规模"而不是"开发者规模"，这一层迟早要做。

**G1. 通用模式（非开发者入口）** `[对齐]`
同一个 Coding 底座，提供"编程模式"和"通用模式"两个入口，通用模式下用户不接触代码。
> Qoder 8 月升级正是这个设计。WorkBuddy 覆盖"办公、开发、设计"。**这是 2026 年头部厂商的一致选择。**

**G2. 移动端 / 小程序轻量入口** `[脑洞]`
手机上用自然语言描述需求 → 云端 Agent 执行 → 结果推回手机。
> 中国最大的流量场在手机，而 AI 编程工具几乎全部缺席移动端。Qoder 已经出了 Mobile 形态，但整体仍是空地。
> 对码道的特殊价值：华为手机是现成的分发渠道。

**G3. "做个小工具"场景化入口** `[脑洞]`
面向非开发者的高频长尾需求：Excel 批处理脚本、数据看板、自动化办公脚本、爬虫、简历网页、小游戏。
> 这类需求的用户量是开发者的几十倍，且产出物天然适合分享（直接接 D3 作品广场）。

**G4. 与华为办公/协同产品打通** `[差异]`
WeLink / 华为云会议 / 华为文档等作为入口和上下文源，对标千问办公之于钉钉、WorkBuddy 之于腾讯文档+企微。

**G5. 编程教育游戏化** `[脑洞]`
把学编程做成闯关 + AI 导师（自动出题、自动批改、自动讲解），面向高校与 K12 信息技术课。
> 用户规模巨大，且是未来开发者的蓄水池。华为在教育侧有渠道基础。

**G6. 求职 / 招聘场景** `[脑洞]`
AI 模拟面试、项目经历打磨、算法题陪练。与招聘平台合作，让"会用码道"成为可检索的技能标签。
> 参考：在 Upwork 上，Cursor / Lovable 已经成为客户直接写在职位需求里的关键词（Lovable 16 个月内提及量 +627%）。**当工具名变成招聘关键词，获客就变成了刚需。** 这条和 F5（认证）是同一个飞轮的两端。

**G7. 开源悬赏 / 众包任务池** `[脑洞]`
企业或开源项目把 issue 挂上悬赏，开发者用码道解决拿积分或现金。
> 给产品带来真实的任务流量和使用场景，同时形成"用码道能赚钱"的心智。

**G8. 硬件 / 智能体联名** `[差异]`
参考 WorkBuddy 开放平台首发 9 款联名智能硬件。华为的硬件矩阵是这条路上最大的资源。

## H. 增长基础设施：不做这些，上面全是空转（8 条）

**H1. 统一积分中台** `[对齐/前置]`
一套积分，可在码道 IDE / CLI / 云端 Agent / 华为开发者空间 / 其他华为云产品之间流通。
> 参考 Trae 的"通用积分 TraeCode/TraeWork 通用"、阿里百炼 Credits 统一计量。**没有统一积分，所有激励类能力都无法组合。**

**H2. 邀请关系链与归因系统** `[前置]`
全链路邀请码、跨端归因（链接 / 二维码 / 深链 / 邀请码手动填写）、多级关系留存。

**H3. 反作弊体系** `[前置]`
设备指纹、行为序列异常检测、**奖励后置发放**（被邀请人达到活跃门槛才发）、单账号封顶、一人一号规则。
> Trae 的规则写得很清楚："每个自然人仅可使用一个账号参与，否则全部参与行为视为无效"。规则要在活动页面上明确公示，避免纠纷。

**H4. 任务中心 / 成长体系** `[前置]`
把 A5（行为换额度）产品化成统一的任务面板，运营可配置，无需每次发版。

**H5. A/B 实验平台与漏斗监控** `[前置]`
至少监控：下载 → 启动 → 登录 → 首次会话 → 首次成功 → 次日回访 → 7 日留存 → 额度耗尽点。
> **额度耗尽点必须单独埋点**，这是当前最可能的流失断崖。

**H6. 分享内容的 SEO / 内容资产化** `[对齐]`
D3/D4 产生的公开页面要可被搜索引擎收录。Lovable 的 9 亿月访问里，有相当比例来自这类长尾页面。

**H7. 运营位与消息触达** `[前置]`
产品内 banner、更新公告、任务完成推送、额度提醒。千问办公上线首月做了 **120 个版本更新**——高频迭代本身需要触达通道才能被用户感知。

**H8. 合规与安全底线** `[前置]`
Agent 权限边界、代码上传的企业合规、生成内容的安全扫描。
> 提醒：2026 年 3 月国家互联网应急中心（CNCERT）曾针对 OpenClaw 发布风险提示，这是监管首次针对开源 AI 智能体发出国家级预警。**做本地权限类能力务必前置合规评审**；反过来，"安全"也可以是码道对政企的卖点（参考 Replit 的 Security Scan、Lovable 的自动 trust center）。
