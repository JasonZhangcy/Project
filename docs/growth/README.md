## 三句话结论

1. **当前的瓶颈不是缺增长玩法，是漏斗前段在失血。** 免费档 500 万 tokens/月不足以让新用户跨过习惯养成线，注册门槛偏重，产品没有任何对外传播出口（自然增长系数≈0）。在这之前做投放和裂变，等于给友商做用户教育。
2. **邀请裂变、分享得积分是标配，但只是效率杠杆**（10%~30% 量级）。真正改变数量级的是四件事：入口卡位、免费门槛、生态供给、独家刚需。
3. **华为在这四件事上都有牌，但都没打**：鸿蒙 1100 万注册开发者、华为认证体系、信创迁移刚需、华为开发者空间的免费云环境。其中"Android → 鸿蒙一键迁移"是最有可能出爆款的单点。

## 数据口径提示

文中引用的友商数据来自公开报道与官方文档，厂商自报口径（注册用户、访问量）差异较大，仅用于判断量级与方向。需要注意注册数与活跃数的差距：Trae 公开数据为注册 600 万 / MAU 160 万，约 27%。**内部决策建议统一使用"周活跃编码用户数（WAU-Coding）"口径**，定义见文档三。
