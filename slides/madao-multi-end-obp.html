HUAWEI CLOUD · 码道 OBP
多端协同能力规划 · 一套 Agent，五端一体
专业开发：IDE / CLI
泛研发办公：Space
云端仓：Web
驾驭面：Mobile
典型使用场景放在架构之上，表现同一任务如何跨端流转
A

工位上云，通勤接着干。IDE 重构中途开会，一键转云端；手机看进度、批高危命令；晚上 CLI apply 回本地审 diff。

B

Space 做完前半段。专家团 + DeepResearch 出方案/原型，一键交给 Web 云端 Agent 改仓开 PR，开发者次日只做审查。

C

值班告警，人不在工位。流水线失败打到微信/元服务，Mobile 派发云端修复并审批出网，Web 出现 PR，Space 同步可见。

D

Agent 装进流水线。CLI 非交互在 CI 预审查；失败升 Web 长程任务；全员在任务总线看见结果，不必进 IDE。

码道 IDE
专业开发者 · 人机结对工作台
  • Next Edit / Agent 测试闭环，人在环内改代码、看 diff
  • Local ↔ Cloud 环境切换，会话可检查点回滚
  • 工程规则 / MCP / 浏览器内验证，不把 IDE 做成聊天窗
码道 CLI
专业开发者 · Agent 引擎与自动化接口
  • 与 IDE 同引擎：CLI 是进程，IDE 是驾驶舱
  • cloud exec / apply 上云回灌，非交互进 CI
  • Skills / MCP / Hooks / 沙箱与 Token 预算，特性先在此落地
码道 Space
泛研发 / 泛办公 · 一站式 AI 工作台
  • 专家 / 专家团、项目空间、技能与连接器
  • Computer Use / Browser Use、DeepResearch、多模态
  • 产物导向；开发任务出口给 Web / IDE，不抢专业编码闭环
码道 Web
云端执行 · Repo 为中心的 Agent 控制台
  • 预热沙箱、长程 / 并行 / 多仓，关盖继续跑
  • 仓 + PR + Agent 同屏（对标 Origin，长在 CodeArts Repo）
  • 仓库事件 Automations；PR 作为云端交接物
码道 Mobile
驾驭与审批面 · 不是迷你 IDE
  • 微信小程序 / 鸿蒙元服务 / App 三入口
  • 看任务、控任务、批权限；可遥控本机或派发云端
  • 竞争力在触达与权限，不在手机上写代码
端云协同怎么协同 同一 Task ID 在五端流转，换的是表面，不是任务身份
STEP 01 · 本地
起草与结对
IDE / CLI / Space 本机开工，带上对话、计划与未提交改动
STEP 02 · 迁移
一键上云
带着现场走：会话上下文 + dirty tree → 云端沙箱接着跑
STEP 03 · 云端
长程执行
Web 沙箱 / Repo / PR，并行 Agent，流水线与预览成为手
STEP 04 · 驾驭
随时审批
Mobile 暂停、追加指令、批高危命令；电脑离线也能派云端
STEP 05 · 闭环
回灌 / 验收
IDE/CLI apply 回本地；Web 开 PR；Space 收可验收产物

本地工作面

  • IDE：高频结对、可视化 diff
  • CLI：无人值守、SSH / CI 脚本
  • Space：专家团把事做完，开发出口给 Web

中枢 · 不是五套产品

统一任务总线 · Agent Runtime · CodeArts Repo

统一账号与权限。任务状态机：草稿 → 执行中（本地/云端）→ 待审批 → 待回灌 → 已关闭。任意端只改状态，不改任务身份。Space 能同步看到 Web 触发的云端任务。

① 全域可见 ② 一键上云（带现场） ③ 一键回灌 ④ 远端驾驭 / 审批

云端与控制面

  • Web：预热沙箱 + 仓/PR/Agent 同屏
  • Mobile：微信 / 元服务 / App 驾驭
  • 友商已能上云，差异在带着 dirty tree 与对话走
